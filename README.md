# PU Syllabus Finder — Version 1

Static, GitHub Pages-ready frontend.

## Files

- `index.html` — page structure
- `style.css` — mobile-first design
- `app.js` — search, filters, details and dark mode
- `data/syllabus.json` — syllabus data

## GitHub Pages

Upload the files to a GitHub repository, then enable:

Settings → Pages → Deploy from branch → main → / (root)

The current JSON contains SAMPLE data only. Replace it with verified syllabus data from the official Panjab University source before public launch.
